# Internationalization (i18n)

This wiki uses [Starlight i18n](https://starlight.astro.build/guides/i18n/). **English is the only active locale** for day-to-day development; the stack stays ready to add more languages later.

| Locale | URL prefix | Content folder |
|--------|------------|----------------|
| English (default) | `/` | `src/content/docs/` |

## Daily workflow (English only)

1. Edit rules in `Kismeta_GameGuide.md`
2. Sync pages: `npm run sync`
3. Preview: `npm run dev` or `npm run preview`

`npm run build` runs `sync` then `astro build`.

## Custom UI strings

Tab labels, guided play chrome, home copy, and flow badges live in [`src/content/i18n/en.json`](../src/content/i18n/en.json). Keys are declared in [`src/content.config.ts`](../src/content.config.ts). Components use `Astro.locals.t('key')`.

## Adding a language

1. Add locale in [`astro.config.mjs`](../astro.config.mjs) (`locales` + sidebar `translations` keyed by BCP-47 `lang`, e.g. `'es'`)
2. Create `src/content/docs/<locale-id>/` mirroring English slugs
3. Add `src/content/i18n/<Lang>.json` for custom UI strings (match `lang` in config)
4. Add `scripts/term-glossary-<locale>.json` and a `LOCALE_CONFIG` entry in [`scripts/translate-locale.mjs`](../scripts/translate-locale.mjs)
5. Populate bilingual data as needed: flows/tables JSON, `guided-steps.ts`, `glossary.<locale>.json`, `context-sections/<locale>.json`
6. Translate docs:

```bash
node scripts/translate-locale.mjs --locale es --only learn/lore,play/setup
```

7. `npm run build` — Pagefind indexes each locale automatically

## Environment

Copy `.env.example` to `.env` and set `OPENAI_API_KEY` when using `translate-locale.mjs`. Never commit `.env`.
