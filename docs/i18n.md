# Internationalization (i18n)

This wiki uses [Starlight i18n](https://starlight.astro.build/guides/i18n/).

| Locale | URL prefix | Content folder |
|--------|------------|----------------|
| English (default) | `/` | `src/content/docs/` |
| Brazilian Portuguese | `/pt-br/` | `src/content/docs/pt-br/` |

## Daily workflow

1. Edit rules in `Kismeta_GameGuide.md`
2. Sync English pages: `npm run sync`
3. Translate to Portuguese: `npm run sync:pt` (requires `OPENAI_API_KEY` in `.env`)
4. Review at `/pt-br/...` with `npm run preview`
5. Adjust terminology in `scripts/term-glossary-pt.json` and re-run translation for affected pages

Translate specific pages only:

```bash
node scripts/translate-locale.mjs --locale pt-br --only learn/lore,play/setup
```

Scaffold empty pt-br frontmatter stubs (English body fallback until translated):

```bash
node scripts/scaffold-pt-br.mjs
```

## Review checklist

- [ ] Game terms match `scripts/term-glossary-pt.json`
- [ ] Internal links use `/pt-br/` prefix
- [ ] Game mode callouts (`game-mode-callout`) still toggle correctly
- [ ] Brazilian friends read Lore + Play sections for natural phrasing

## Adding another language

1. Add locale in `astro.config.mjs` (`locales` + sidebar `translations`)
2. Create `src/content/docs/<locale>/` mirroring English slugs
3. Add `scripts/term-glossary-<locale>.json` and a `LOCALE_CONFIG` entry in `translate-locale.mjs`
4. Optional: `src/content/i18n/<lang>.json` for custom UI strings

## Environment

Copy `.env.example` to `.env` and set `OPENAI_API_KEY`. Never commit `.env`.
