title: "Card Values & Scoring"
description: "Point values for Minor and Major Arcana cards."
---

### Minor Arcana (Numbered Cards)

| Card | Value |
|------|-------|
| Ace | 1 or 11 points |
| 2–10 | Face value |
| Page | 11 points |
| Knight | 12 points |
| Queen | 13 points |
| King | 14 points |

### Major Arcana (Special Cards)

Major Arcana cards give you a choice — use the card's **base value** (the Roman numeral shown):

| Card | Value |
|------|-------|
| The Magician (I) | 1 |
| The High Priestess (II) | 2 |
| The Lovers (VI) | 6 |
| The World (XXI) | 21 |
