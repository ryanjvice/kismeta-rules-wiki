# Brand assets

Drop your GOODMAGIK / Kismeta brand files here, then update `src/styles/custom.css` and `astro.config.mjs` as needed.

Suggested files:

- `logo.svg` — header logo (replace `src/assets/logo.svg` or update config)
- `favicon.svg` / `icon-192.png` / `icon-512.png` — PWA icons
- `colors.json` — optional hex values for theme variables
- `fonts/` — webfont files if not using Google Fonts

After adding assets, run `npm run build` to verify the PWA manifest picks up new icons.
